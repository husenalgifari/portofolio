# 🚀 Web Portfolio Profesional & Modern Web Developer

Portofolio digital modern, estetik, dan interaktif yang dibangun khusus untuk **Web Developer**, mahasiswa teknik informatika, maupun software engineer profesional.

---

## ✨ Fitur Utama

- 🎨 **Desain Estetik & High-Tech (Cyber Glow & Glassmorphism)**: Tampilan visual dengan efek frosted glass, border glow gradien, dan palet warna yang memanjakan mata.
- 🌌 **Interactive Constellation Canvas**: Background partikel interaktif di canvas HTML5 yang bereaksi halus terhadap gerakan mouse pengguna.
- ⌨️ **Dynamic Typing Motto**: Teks animasi mesin tik untuk peran dan moto profesional web developer.
- 🧑‍💻 **Profil & About Me**: Kartu profil holografik, ringkasan bio, dan mockup code editor TypeScript.
- 🎓 **Pendidikan & Kampus (Universitas Indonesia / Custom)**: Kartu institusi pendidikan lengkap dengan gelar S1, IPK Kumulatif (Cum Laude), dan pencapaian capstone/organisasi.
- 📊 **Stats Counter Live**: Animasi counter angka otomatis saat di-scroll ke dalam viewport.
- 🛠️ **Skills Matrix Terkategori**: Tab interaktif untuk kategori *Frontend*, *Backend*, dan *Database/DevOps* dengan animasi bar persentase kemampuan.
- 💼 **Portofolio Projek Unggulan**:
  - Filter kategori (*Full-Stack*, *Frontend*, *Backend/API*).
  - Kartu proyek dengan thumbnail resolusi tinggi SVG UI mockup.
  - **Quick View Modal Dialog** untuk melihat deskripsi lengkap, fitur unggulan, tech stack, demo live, dan source code GitHub.
- 📜 **Pengalaman Kerja & Organisasi**: Garis waktu vertikal (*timeline*) dengan badge peran, perusahaan, tanggal, dan rincian pencapaian.
- 🏆 **Sertifikat Terverifikasi**: Kartu sertifikasi (AWS, Google Cloud, Dicoding, Meta) dengan modal verifikasi dan ID kredensial.
- 📬 **Kontak & Hire Me**:
  - Form pesan interaktif dengan simulasi pengiriman dan notifikasi Toast.
  - Tombol **1-Click Copy** untuk menyalin email dan nomor telepon.
  - Tombol direct **WhatsApp Click-to-Chat** dengan pesan otomatis.
- 🔊 **Synthesized Web Audio**: Efek suara sintetis futuristik menggunakan Web Audio API tanpa butuh file audio eksternal.
- 🎨 **Palette Switcher**: Pilihan 4 tema aksen warna (Cyber Violet, Neon Cyan, Matrix Emerald, Sunset Amber).
- 📱 **100% Responsif**: Dioptimalkan untuk Smartphone, Tablet, Laptop, dan Desktop 4K dengan mobile navigation drawer.

## 🚀 Cara Menjalankan Portofolio

### Cara 1: Langsung Buka di Browser (Paling Mudah)
Cukup klik dua kali berkas [`index.html`](file:///c:/Users/ASUS/OneDrive/Documents/ITSME%20PROJEK/porto/index.html) di file explorer komputer Anda, dan halaman web akan langsung terbuka secara offline di browser (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).

### Cara 2: Menjalankan dengan Local Web Server
Buka terminal di folder ini, lalu jalankan:
```bash
python -m http.server 8080
```
Lalu akses melalui browser di: `http://localhost:8080`
