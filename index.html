Hasil Karya & Implementasi

Koleksi aplikasi web dan mobile simple yang telah saya kembangkan.

Full-Stack Web

Point Of Sale On Coffee

Sistem Point of Sale (POS) On Coffee Space ini dikembangkan menggunakan PHP dan MySQL untuk mengoptimalkan transaksi kasir serta manajemen stok secara real-time. Platform berbasis web ini sudah terintegrasi dengan payment gateway untuk mendukung pembayaran non-tunai, sekaligus menyajikan laporan penjualan harian secara otomatis dan akurat.

Mobile Application

Aplikasi Dapur Pintar (Resep Masakan)

Aplikasi Dapur Pintar ini dikembangkan sebagai tugas akhir. Platform ini dirancang untuk memudahkan pencarian resep masakan, menggunakan Flutter sebagai framework untuk membangun antarmuka yang responsif dan menarik. Aplikasi terintegrasi dengan API backend RESTful yang mengelola data resep secara dinamis, mencakup fitur penambahan, pengeditan, dan penghapusan resep.

Full-Stack Web

Website Pemesanan Tiket Goa Lawah

Website Pemesanan Tiket Goa Lawah ini dikembangkan sebagai bagian dari penyelesaian tugas penelitian. Proyek ini dibuat menggunakan PHP dengan basis data MySQL, serta didukung HTML, CSS, dan JavaScript untuk menghadirkan pengalaman pengguna yang interaktif dan responsif dalam alur reservasi tiket, konfirmasi pembayaran, serta pencetakan bukti tiket digital.

Frontend Web

Web Photobooth Interactive

Website Photobooth ini dikembangkan menggunakan HTML, CSS, dan JavaScript. Antarmuka yang simpel membuatnya mudah digunakan oleh siapa saja untuk mengambil foto dan mengabadikan momen langsung melalui peramban web dengan dukungan kamera web secara instan.
